# 🧠 AI-Based Therapeutic Companion System

## 📌 Overview
An AI-powered mental health companion system that helps users improve their well-being through chatbot interaction, mood tracking, and personalized insights.

---

## 🚀 Features
- 💬 AI chatbot for mental health support  
- 📊 Mood tracking and analysis  
- 😴 Sleep monitoring  
- 📈 User dashboard with reports  
- 🔐 Login and signup authentication  

---

## 🛠️ Tech Stack
- Frontend: React.js, CSS  
- Tools: Git, GitHub  

---
