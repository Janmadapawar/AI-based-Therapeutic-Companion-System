# 🧠 AI-Based Therapeutic Companion System

> An AI-powered mental health companion that provides empathetic chatbot support, mood tracking, sleep monitoring, and personalized wellness insights — all in one responsive web application.

---

## 🌟 Features

| Feature | Description |
|---|---|
| 💬 AI Chatbot | Conversational mental health support with context-aware, empathetic responses |
| 📊 Mood Tracker | Log and visualize daily mood patterns over time |
| 😴 Sleep Monitor | Track sleep quality and duration with trend analysis |
| 📈 Wellness Dashboard | Personalized reports and insights based on user data |
| 🔐 Auth System | Secure login and signup with session management |

---

## 🛠️ Tech Stack

**Frontend**
- React.js (component-based UI)

- JavaScript (ES6+)

## ⚙️ Installation & Setup

```bash
# 1. Clone the repository
git clone https://github.com/Janmadapawar/AI-based-Therapeutic-Companion-System.git

# 2. Navigate to the frontend directory
cd AI-based-Therapeutic-Companion-System-main/frontend/therapy-ai-frontend

# 3. Install dependencies
npm install

# 4. Start the development server
npm start
```

The app will run at `http://localhost:3000`

## 💡 How It Works

1. **User signs up / logs in** → Secure authentication flow
2. **Interacts with AI Chatbot** → Receives supportive, context-aware responses
3. **Logs mood and sleep daily** → Data stored and tracked over time
4. **Views Dashboard** → Personalized wellness insights and trend reports
